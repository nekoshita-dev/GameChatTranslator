# GameChat Translator

海外のプレイヤーとゲーム内のテキストチャットで話すための、Windows用の翻訳ツールです。

- **自分の発言**：キーを押しながら日本語で話す → 英語に翻訳 → ゲームのチャットに自動で入力・送信
- **相手の発言**：画面のチャット欄を読み取り、英語・中国語を日本語に翻訳して画面に重ねて表示
- **ゲームごとの設定**：チャットキーや用語辞書をゲームごとに切り替え。ファイルを1つ追加するだけで新しいゲームに対応できます
- **辞書**：「gg」「ns」「666」「牛逼」などのスラングや、「裏取り → flank」のようなゲーム用語を自分で追加して精度を上げられます

## 対応ゲーム

| ゲーム | プロファイル名 | 備考 |
|---|---|---|
| Battlefield 6 | `bf6` | 作者が普段使っているゲーム |
| Apex Legends | `apex` | チャットキーは初期設定（Enter）を想定 |
| VALORANT | `valorant` | Enter = チーム、Shift+Enter = 全体を想定。下の注意を参照 |
| Rainbow Six Siege | `r6s` | U = チーム、Y = 全体を想定 |
| その他（Enterでチャット） | `generic` | 汎用 |

BF6以外は、初期設定のキー配置を想定した設定です。動かないときや、ゲーム内でキーを変えている場合は `profiles/<ゲーム>.toml` を書き換えてください。動作報告や修正は大歓迎です（[CONTRIBUTING.md](CONTRIBUTING.md)）。

## 必要なもの

- Windows 10 / 11
- Python 3.11 または 3.12（https://www.python.org からインストールし、「Add python.exe to PATH」にチェック）
- マイク
- （あると快適）NVIDIA のGPU。無くても動きますが、音声の変換が遅くなります

## インストール

1. このリポジトリをダウンロード（緑の「Code」→「Download ZIP」）して展開
2. `setup.bat` をダブルクリック
3. NVIDIA のGPUがある場合は、続けて `setup_gpu.bat` をダブルクリック
4. `check.bat` をダブルクリックして動作チェック（ゲームは起動しなくてOK）。途中で「2秒間、何か話してください」と出たらマイクに向かって話します。すべて OK なら準備完了です

## 使い方

1. `run.bat` をダブルクリック（管理者権限の確認が出たら「はい」）。アプリの画面が開きます。初回は音声認識モデルのダウンロードで数分かかります（画面上部が「準備中…」の間）
2. 画面上部の「ゲーム」で遊ぶゲームを選ぶ（切り替えるとアプリが再起動します）
3. 「設定」でマイクや翻訳方法、ショートカットキーなどを変えられます（保存すると再起動して反映）
4. ゲームの画面モードは **「ボーダーレスウィンドウ」** がおすすめです（フルスクリーンでも動きますが、翻訳の表示枠が見えないことがあります。下の「フルスクリーンで遊ぶとき」を参照）

### アプリの画面

- **自分の発言**：オン/オフ、録音キー、マイクの音量メーター（話すとバーが動きます）、翻訳方法と音声認識モデル
- **相手のチャット**：オン/オフ、読み取る範囲、撮影方法。「範囲を選び直す」を押すと、3秒後にゲーム画面を撮ります
- **会話ログ**：送信した発言（日本語 → 英語）と、翻訳した相手の発言（英語・中国語 → 日本語）が並びます
- **下の帯**：ショートカット一覧と、最新のお知らせ
- 「ログ」「動作チェック」ボタンで、記録ファイルや動作チェックを開けます

コマンドプロンプトから使える便利な指定：

| コマンド | 内容 |
|---|---|
| `run.bat --game apex` | 一時的に別のゲームで起動 |
| `run.bat --list` | 使えるゲームの一覧 |
| `run.bat --devices` | 使えるマイクの一覧 |

### 自分の発言を送る

**F8 を押しながら日本語で話して、離す** → 英語に翻訳されてチャットに送信されます。

- 「ピッ」（高い音）＝録音開始、「ポッ」（低い音）＝録音終了、短い高い音＝送信完了
- 「ブー」（低く長い音）＝聞き取れなかった、またはエラー
- チームチャットと全体チャットを使い分けたいときは、`settings.toml` の `alt_hotkey` に2つ目のキーを設定します（送り先はプロファイルの `alt_open_key`）

### 相手の発言を翻訳する

1. ゲーム中、チャットが表示されている状態で **F9** を押す（「ピッ」と鳴ってゲーム画面を撮ります）
2. ゲームから出たとき（Alt+Tab、マッチの合間など）に、撮った画面が暗く表示されるので、相手の発言が出るあたりを **マウスでドラッグして囲む**
   - フルスクリーンでもゲームが後ろに下がらないよう、囲む画面は「ゲームから出たとき」に出ます
   - ウィンドウ表示のゲームなら、F9 を押してすぐに囲む画面が出ます
   - 範囲はゲームごとに保存されるので、最初の1回だけでOKです
3. 新しい発言が出ると、日本語訳が表示されます（初期設定ではチャット欄の上）

- **F7**：翻訳の表示枠を動かす「移動モード」。ドラッグで移動、ホイールで文字の大きさ、Shift+ホイールで幅、右クリックで自動の位置に戻す。もう一度 F7 で確定（ゲームごとに保存）。**2台目のモニターに置く**こともできます
- **F10**：翻訳表示のオン/オフ
- **F11**：辞書・無視リストを読み込み直す
- 翻訳はコンソール画面（黒い画面）にも表示されます

### フルスクリーンで遊ぶとき

- 画面の読み取りは、フルスクリーンでも撮れる方法（Windows の Desktop Duplication。OBS の画面キャプチャと同じ仕組み）を使います
- ただし翻訳の表示枠は、フルスクリーンのゲームの上には表示されないことがあります。その場合は **F7 で表示枠を2台目のモニターに動かす**か、ゲームを「ボーダーレスウィンドウ」にしてください

## 設定

ふだんはアプリの「設定」画面で変更できます。画面に無い細かい項目は `settings.toml` で変更できます（初回起動時に `settings.default.toml` から作られ、アプリを更新しても上書きされません。分からなくなったら消すと初期設定に戻ります）。主な項目：

| 項目 | 内容 |
|---|---|
| `game` | 使うゲームプロファイル |
| `[voice] hotkey` | 録音キー（`"mouse4"` でマウスのサイドボタンも可） |
| `[voice] translator` | `"google"`（無料・辞書が効く）/ `"deepl"`（自然・APIキー必要）/ `"whisper"`（ネット不要） |
| `[voice] auto_send` | `false` にすると入力だけして、送信は自分で Enter |
| `[voice] vad_threshold` | 小さい声が拾われないときは下げる |
| `[voice] input_device` | 使うマイク。番号か名前の一部（例：`"Yeti"`）。一覧は `run.bat --devices` |
| `[chat_translate] my_name` | 自分のプレイヤー名（自分の発言を翻訳しない） |
| `[overlay] position` | 翻訳の表示位置（`above` / `below` / `right`）。F7 の移動モードで動かした場合はそちらが優先 |
| `[api] deepl_key` | DeepL の APIキー（https://www.deepl.com/pro-api で無料キーを取得可） |

## 辞書で精度を上げる

辞書は Excel やメモ帳で編集できる CSV ファイルです（UTF-8 で保存してください）。

| ファイル | 内容 |
|---|---|
| `dict/slang_en.csv` | 英語のスラング・略語（全ゲーム共通） |
| `dict/slang_zh.csv` | 中国語のスラング（全ゲーム共通） |
| `dict/speech_ja.csv` | 自分の発言のゲーム用語（全ゲーム共通） |
| `profiles/<ゲーム>.slang.csv` | そのゲーム専用のスラング |
| `profiles/<ゲーム>.speech.csv` | そのゲーム専用の用語 |
| `user/slang.csv`・`user/speech.csv` | **自分用の辞書**（全ゲーム共通。初回起動時に作られ、アプリを更新しても上書きされません） |

**スラング辞書**（`term,expand,ja`）
- `term`：チャットに出てくる言い方
- `expand`：文の中に出てきたとき、翻訳する前に置き換える正式な言い方
- `ja`：その語だけの発言だったとき、翻訳せずにそのまま表示する訳

例：`ns,nice shot,ナイスショット` → 「ns」だけなら「ナイスショット」と表示。「ns bro」なら「nice shot bro」にしてから翻訳。

**用語辞書**（`ja,en`）
- 話した日本語の中の用語を、翻訳の前に英語へ置き換えます。音声認識にも「この単語が出てくるかも」と教えるので、聞き間違いも減ります
- 例：`裏取り,flank` → 「裏取りして」→「flank して」→ 翻訳 →「Flank」

同じ語があるときは「自分用 → ゲーム専用 → 共通」の順で優先されます。自分で追加する語は `user/` に書いておくと、アプリを更新しても消えません。良い語ができたら、ぜひ Pull Request で共有してください。

## うまくいかないとき

- **文字が入らない・欠ける**：プロファイルの `open_delay` を 0.3、`key_delay` を 0.03 くらいに増やす
- **全角になる**：プロファイルの `ime_off = true`（初期値）で、入力中だけ日本語入力をオフにします。それでもなる場合は、ゲーム中は Windows の入力方式を英語キーボードにしてください
- **キーに反応しない**：`run.bat` から起動しているか（管理者権限が必要）を確認
- **聞き取りが悪い**：録音ごとに「マイク音量」が表示されます。-40dB より小さいときは Windows のサウンド設定でマイクの入力音量を上げる
- **翻訳が表示されない**：画面モードを「ボーダーレスウィンドウ」に。F9 で範囲を選び直す
- **自分が入力中の文字まで翻訳される**：F9 で範囲を選ぶとき、チャットの入力欄を含めないように囲む
- **「すでに起動しています」と出る**：前のウィンドウが残っていないか確認して閉じる
- **ゲームが別のモニター**：`[chat_translate] monitor` を 2 などに
- **詳しいエラーを見たい**：`debug = true`
- **どこが悪いか分からない**：`check.bat` で動作チェック。結果は `data/logs/check.txt` に保存されます
- **不具合を報告したい**：`data/logs/gamechat.log` に起動中の記録が残っています。GitHub の Issue に貼ってください（チャットの内容が含まれるので、必要に応じて伏せてください）

## 注意

- **アンチチートについて**：このツールはゲームにキー入力を送り、画面を撮影します。ゲームのファイルやメモリには一切触れませんが、各ゲームのアンチチート（EA Javelin、Easy Anti-Cheat、BattlEye、Riot Vanguard など）が反応しない保証はできません。**利用は自己責任**で、まずは練習モードやカスタムマッチで試してください。特に VALORANT（Vanguard）は自動入力に厳しく、動かない可能性があります。
- 送信できるのは英数字と記号だけです（キー入力で送るため）。
- `google` 翻訳は非公式の方法で Google翻訳を使っています。予告なく使えなくなることがあります。安定して使いたい場合は DeepL の APIキーを設定してください。
- 翻訳のために、話した内容・読み取ったチャットが翻訳サービス（Google / DeepL）に送られます。`[voice] translator = "whisper"` なら自分の発言はPCの外に出ません。
- マイクは起動中ずっと開いたままです（キーを押す直前の声も拾うため）。使われるのはキーを押している間（＋前後の少し）の音声だけです。
- 各ゲームの名称は各社の商標です。このツールは各ゲーム会社とは関係ありません。

## 更新するには

新しい版のファイルで上書きして、`setup.bat` をもう一度実行してください。`settings.toml`・`user/`・`data/` は上書きされません。変更点は [CHANGELOG.md](CHANGELOG.md) を見てください。
